Optimize your WordPress admin panel by removing clutter and improving performance. Frontend unaffected.

== Description ==

Admin Cleaner & Speed Booster helps you optimize the WordPress admin panel by:

* Removing unnecessary dashboard widgets
* Hiding admin notices
* Disabling unused scripts and styles
* Controlling the Heartbeat API
* Customizing the admin experience per role

**Important:** This plugin only affects the WordPress admin panel. Your frontend site remains completely unaffected.

= Free Features =

* Remove dashboard widgets
* Hide admin notices
* Disable Gutenberg editor per role
* Control Heartbeat API
* Disable emojis and embeds in admin
* Unload specific scripts and styles
* Custom admin footer text
* Role-based controls
* Admin analytics dashboard
* Custom admin logo
* White-label admin interface
* Import/export settings

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/admin-cleaner-speed-booster`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Admin Cleaner' in your WordPress admin menu
4. Configure your settings

== Frequently Asked Questions ==

= Will this affect my frontend site? =

No. All optimizations apply only to the WordPress admin panel. Your frontend remains completely unaffected.

= What happens if I disable the wrong script? =

You can use the "Reset to Defaults" button to restore all settings. Additionally, you can deactivate the plugin to remove all customizations.

= Is this compatible with page builders? =

Yes. This plugin only affects the admin panel, not your page builder or frontend tools.

= Does this work with multisite? =

Multisite support is available in the Pro version.
